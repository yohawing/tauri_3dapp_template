Execute one plan at a time in the order below. Each executor must read its plan

## Objective and non-goals

The objective is to remove the highest-confidence lifecycle, canonical-state,
and dead-UI defects found in the 2026-08-10 architecture audit before adding
more PoC features.

Non-goals for this queue:

- Do not expand Canvas into a full Native renderer mirror.
- Do not add Key/Clip editing, Undo/Redo, Graph Editor, a generic
  `TemporalDocument`, an Asset Browser, or an asset database.
- Do not broadly split `renderer.rs`, `App.tsx`, or `Timeline.tsx` merely because
  they are large. Extract only the testable state boundaries required by these
  plans.
- Do not modify `vendor/kiss3d-toon`, commit, push, or open a PR without a
  separate operator instruction.

- 001 goes first because all later GUI gates assume Native/Canvas activity and
  recovery state are trustworthy.

  model must be settled before canonical/display time is separated.
- 004 and 005 are semantically independent of Timeline, but remain serialized
  to honor this repository's dependency-ordered TODO workflow and to keep GUI
  evidence attributable to one change at a time.
- Each behavior-changing plan adds its characterization/regression test before
  or together with the fix. There is no separate test-infrastructure plan.

## Findings considered and rejected

- Broadly split large modules now: rejected because file size alone is not a
  defect, and it would obscure the behavioral fixes without an adequate
  characterization boundary.
- Split the asset loader and Timeline metadata parser immediately: rejected for
  this batch because it requires high-risk vendor/API work without a measured
  Open/Import event-loop stall threshold.
- Remove `ShellComponentsPage`, `ShellComparisonPage`, or full Timeline variant:
  rejected because they are reachable design/evidence surfaces, not dead code.
- Implement the Inspector Rendering controls instead of removing them: rejected
  because rendering properties are outside the current Native Scene command
  contract and current PoC critical path.
